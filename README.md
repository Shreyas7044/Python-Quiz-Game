# Python-Quiz-Game
A simple Python quiz game where users answer multiple-choice questions. Built using only core Python (no external libraries). Demonstrates input handling, conditional logic, scoring mechanism, and user interaction. Beginner-friendly and reusable for learning Python basics.

This is a simple Quiz Game built using core Python. The user answers
multiple-choice questions, earns marks for each correct answer, and
receives a final score at the end.

## 📌 Features
✔ Beginner-friendly  
✔ No external libraries required  
✔ Interactive question answering  
✔ Score calculation and result display  

## 🧾 How the Quiz Works
1️⃣ User is welcomed  
2️⃣ User confirms if ready to play  
3️⃣ 4 Questions are asked  
4️⃣ Each correct answer = 10 marks  
5️⃣ Final score and performance message displayed  

## 🛠 Requirements
- Python 3+

No additional packages are needed.

2. Open terminal / command prompt in project folder
